## Integrated Research Workflow `[稿]`

三個步驟，卡片之間有箭頭。這是流程敘述，不是產品規格。

### 1. Sample Preparation

- **卡片內文** `[稿]`
  Controlled handling and standardized molecular workflows.

- **延伸段落** `[草稿]`
  Everything downstream inherits the quality of this step. Samples are handled
  under defined conditions so that what reaches analysis reflects the biology
  rather than the handling.

### 2. Automated Analysis

- **卡片內文** `[稿]`
  Instrument-supported processing designed for consistency and traceability.

- **延伸段落** `[草稿]`
  Automation here is about repeatability rather than throughput. Consistent
  execution means a difference between two results can be attributed to the
  samples instead of to the run.

### 3. Data Interpretation

- **卡片內文** `[稿]`
  Structured analysis supporting research questions and collaboration.

- **延伸段落** `[草稿]`
  Analysis is structured so that a result can be traced back to the conditions
  that produced it, and so that collaborators can examine the reasoning rather
  than only the conclusion.

## Why It Is Built This Way `[草稿]`

選用區塊。純設計理念敘述，不涉及規格宣稱。

The three stages are treated as one system rather than three handoffs. A
constraint in analysis changes how a sample should be prepared; an ambiguity in
interpretation sends a question back upstream. Keeping them connected is what
makes a result reproducible outside the run that produced it.
