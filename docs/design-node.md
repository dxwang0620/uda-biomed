# UDA BIOMED — 設計稿萃取紀錄

本文件記錄 `src/styles/tokens.css` 每個值的來源。**所有色值皆為實際取樣，非目測。**
若之後有人想改 token，請先讀這裡，確認要改的是「取樣值」還是「推導值」。

---

## 取樣方法

設計稿為四張 PNG，皆為 `1536 × 1024`。本機無 PIL 與 ImageMagick，改用 ffmpeg 解碼：

```bash
ffmpeg -i web_img/<檔名>.png -f rawvideo -pix_fmt rgb24 <檔名>.raw
```

再以 Python 直接讀 raw RGB 逐像素分析，兩種取法分開處理：

- **純色區塊**（色帶、按鈕、圓形、底色）→ 對區域內像素做**量化眾數**（quantise step 4）。
  設計稿是算圖，帶有輕微雜訊，眾數比單點取樣穩定。
- **文字與線條** → 先取區域內亮度最低的 12% 像素（字身核心，排除反鋸齒邊緣），
  再對這些像素做量化眾數（step 6）。直接取最小值會過度飽和，直接取單點會取到反鋸齒。

亮度公式：`0.2126 R + 0.7152 G + 0.0722 B`

四張稿代號：`home` / `about` / `research` / `tech`（對應 web_img 內四個 uuid 檔名）。

## 元件慣例

### 卡片

- **沒有 1px border。** 白卡（`#ffffff`）放在近白底（`#fdfdfd`）上，靠柔和陰影分離。
- 掃描 research 卡片左緣（`y=830`，`x` 由 78 往右）得到連續漸層：
  `#fdfdfd #fdfdfd #fdfdfd #fcfcfd #fbfbfc #fafafb #f9f8f9 #f7f7f8 #f6f5f7 #f4f4f5` → 卡內 `#fefefe`
- 落差範圍約 **10px**，最深處僅比底色暗約 **3.5%**。這是 `--shadow-card` 的 alpha 壓到 0.05 的依據。
- 圓角實測 **4–5px**（掃 TL 角，對角線約跨 5 個像素）。

### 按鈕

- 首頁實心 CTA：高度實測 **56px**，圓角實測 **2–3px**（掃 TL 角，對角線僅跨 2–3 像素）。
- 幾乎是方角。`CLAUDE.md` 佔位的 `--radius: 8px` 會明顯太圓。
- 首頁 hero 為雙按鈕：實心「OUR RESEARCH」+ 白底藍框「CONTACT US」。

### 導覽

- 當前頁底線實測 **3px**（research 頁 `y=97,98,99` 為 navy，`y=96` 與 `y=100` 已是反鋸齒）。
  `CLAUDE.md` 寫 2px，已在 token 改為 3px。
- 導覽連結字身核心 `#06185a` / `#000c4e`，屬 navy 色系。

### 波浪色帶（全站簽名元素）

每一頁 hero 底部都有一道 navy 曲線，**左薄右厚**，右側疊分子網格圖形。
以 about 頁最乾淨（hero 照片本身不含藍色，不會污染偵測）：

色帶下緣 `y = 643`。上緣曲線（1536×1024 座標系）：

| x | 96 | 192 | 288 | 384 | 480 | 576 | 672 | 768 | 864 | 960 | 1056 | 1152 | 1248 | 1440 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| y | 587 | 598 | 604 | **606** | 604 | 600 | 593 | 585 | 576 | 564 | 547 | 534 | 515 | **400** |

形狀：左端厚 56px → 在 `x≈384`（約 25% 寬）微微下沉到最薄 37px → 之後穩定上揚 → 右端厚 243px。

> `x=1344` 的取樣值（423）受右側網格圖形干擾，已排除。
> home / research / tech 三頁的 `x>800` 區段同樣受 hero 照片內的藍色物件干擾，故以 about 為準。

實作方式：SVG `path`，非 CSS `border-radius` 或 `clip-path`。

## 字體

設計稿為算圖，**無法反查字檔**。字形觀察：雙層 a、單層 g、水平收筆的人文無襯線，
與 **Inter** 高度接近（`CLAUDE.md` 的 `--font-latin` 本來就是 Inter）。
標題面感覺略寬一點，若要更貼近可考慮 Archivo，但差異在算圖上不足以判定。

語言已確認**只做英文**，故 `--font-display` / `--font-body` / `--font-latin` 三者統一為 Inter，
不載入 Noto Sans TC。
